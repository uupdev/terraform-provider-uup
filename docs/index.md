# You Up? Provider

[You Up?](https://uup.dev) checks your websites, APIs, servers and cron jobs from several locations, and alerts you only when an outage is confirmed. This provider manages its Monitors and Notification rules through the [public API](https://docs.uup.dev/api/).

## What it manages

- `uup_monitor`: `http`, `tcp`, `ping` and `heartbeat` Monitors, with their performance, certificate and domain Checks, pause, and assigned rules.
- `uup_notification_rule`: which events go to which Channels.

Channels are added and verified in the dashboard, because most need a code or a link confirmed by a person. Look them up with the `uup_channel` data source.

## Authentication

Make an API token of the **Full** kind on the dashboard's **API tokens** screen ([how](https://docs.uup.dev/api/tokens/)). A token made for one Project reaches only that Project. Give the token to the provider in the `UUP_API_TOKEN` environment variable, or in `api_token`.

## Example Usage

```terraform
terraform {
  required_providers {
    uup = {
      source = "uupdev/uup"
    }
  }
}

# The token is read from UUP_API_TOKEN when api_token is left out.
provider "uup" {}
```
